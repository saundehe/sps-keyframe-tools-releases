# SPS Keyframe Tools - releases

Downloads for Silent Partners Studio Keyframe Tools, one panel for After Effects and Premiere Pro.
A licence file is required to use the panel; ask Silent Partners Studio for one.

Grab the latest from **Releases**:
- `sps-keyframe-tools_vX.Y.Z_win.zip`: unzip, right-click `install.ps1` > Run with PowerShell.
- `sps-keyframe-tools_vX.Y.Z_mac.zip`: unzip, right-click `install_mac.command` > Open.

Then open After Effects or Premiere > Window > Extensions > SPS Keyframe Tools.
The panel checks here for updates when it opens.

Source is private. This repo holds release files only.
